# Команды

Каналы, роли и пользователи выбираются из стандартных пикеров Discord; `set`/`unset` и `access grant`/`access revoke` автодополняют опции `path`/`command`.

`/nep` видна каждому участнику с самого начала; доступ проверяется для каждой команды в момент вызова, а не через видимость команд в Discord. Владельцы (`bot.owners`) всегда могут выполнять любую команду. Остальным нужно разрешение: `/nep access grant <command> [role] [user]` открывает один ключ команды (напр. `memory.show`), целую группу (напр. `memory`) или все команды (`*`) всем (без роли/пользователя), роли или пользователю; `/nep access revoke` отменяет разрешение; `/nep access list` показывает текущие разрешения. Без разрешения участник без прав владельца, выполняющий `/nep`, получает эфемерный ответ "Not allowed". `private.show`, `private.forget` и `private.purge` доступны только владельцам и исключены из всех разрешений; `access grant` отклоняет их, а `access list` не показывает. Группы `mentor` и `access` доступны только владельцам точно так же и не могут быть выданы через разрешения.

| Команда | Описание |
|---|---|
| `/nep status` | Модель, калибровка, квоты (LLM-запросы с полуночи, счётчик картинок и модель изображений, просмотры GIF, обновления портретов), статус памяти по серверу (профили, буфер, следующий спонтанный), размер голосовой очереди и сегодняшние голосовые запросы (при двухэтапном режиме), приватный чат вкл/выкл и количество приватных файлов |
| `/nep reload` | Перезагрузить конфигурацию и промпты сейчас же |
| `/nep ping [role]` | Отправить минимальный запрос к одной или всем ролям модели (`voice`, `analyzer`, `classifier.text`, `classifier.media`, `classifier.video`, `mentor`, `image`), следуя маршруту `llm.providerByModel` каждой роли, и показать модель, задержку, провайдера, токены или ошибку; `/nep ping classifier` пингует все три классификатора. Строки моделей печатаются вместе, затем проверки API-ключей: `youtube: API key — {status}` (например `ok`, `not needed (yt-dlp ok)`, `missing (blocked)`) и `web: API key — {status}` (`ok`, `missing` или `off`). `role:image` проверяет `image.model` по публичному листингу моделей провайдера (один бесплатный GET, без генерации) и подтверждает, что модель зарегистрирована и выдаёт изображения; успешная проверка не гарантирует, что генерация удастся. Без указания роли проверка image идёт после остальных строк моделей. Не учитывается в `llm.maxRequestsPerDay` и работает на паузе или во время прогрева |
| `/nep pause` | Остановить всю активность, сбросить память на диск и выгрузить; текущий прогон ментора останавливается и его отчёт публикуется до сброса. `data/` безопасно редактировать на паузе |
| `/nep resume` | Перезагрузить память из `data/` и продолжить; отказывает, если хоть один JSON-файл не разбирается, и перечисляет сломанные |
| `/nep interject [channel]` | Немедленно вклиниться в разговор в указанном канале |
| `/nep initiate [channel]` | Немедленно начать тему в указанном канале |
| `/nep draw <text> [self]` | Нарисовать одну картинку через промпт рисования. Ответ только вам (эфемерный с прикреплённой картинкой). Тратит баланс в счёт `image.maxPerDay`, но не в лимит участника. Отклоняется на паузе. НЕ зависит от `features.imageGeneration` |
| `/nep set <path> <value>` | Переопределить значение конфигурации (пишет в `config.local.json`). Пути в `bot.owners` и `bot.access` доступны только владельцам, даже если участнику выдано разрешение на `set`. Значение должно быть того же JSON-типа, что и текущее, а путь должен указывать на конечный ключ |
| `/nep unset <path>` | Удалить переопределение конфигурации. Те же ограничения на владельца и конечные ключи, что и у `set` |
| `/nep rule add <text>` | Добавить правило в `prompts.local/rules.md` |
| `/nep rule list` | Показать правила с нумерацией |
| `/nep rule remove <number>` | Удалить правило по номеру |
| `/nep model show` | Показать активные модели для каждой роли (`voice`, `analyzer`, `classifier.text`, `classifier.media`, `classifier.video`, `mentor`, `image`) |
| `/nep model set <role> <id>` | Установить модель для роли (`voice`, `analyzer`, `classifier.text`, `classifier.media`, `classifier.video`, `mentor`, `image`) |
| `/nep route list` | Все маршруты из `llm.providerByModel`, затем текущая модель каждой роли и применяемая к ней маршрутизация. Ключ доступа `route.list` (только чтение) |
| `/nep route set <model> <providers> [role] [fallbacks]` | Направить префикс модели только через указанных провайдеров. `model` — id модели или префикс (напр. `google/`, без `@` и пробелов). `providers` — список slug провайдеров через запятую (напр. `google-vertex`; строчные буквы, цифры и дефисы). `role` ограничивает маршрут одной ролью (по умолчанию: любая). `fallbacks` разрешает другие провайдеры при недоступности (по умолчанию: false). Записывает `{ "only": [...], "allow_fallbacks": ... }` в `config.local.json` под `llm.providerByModel` и перезагружает. Ключ доступа `route.set` |
| `/nep route remove <model> [role]` | Удалить маршрут. Ключ должен существовать в `config.local.json`; ключ, заданный только в `config.json`, этим способом не удаляется. Ключ доступа `route.remove` |
| `/nep memory show <user> [section] [limit] [order]` | Без секции: краткая сводка. Секции: `character`, `style`, `relationship`, `affinity`, `aliases`, `interests`, `details`, `episodes`, `raw` (сохранённый JSON). Секции-списки принимают `limit` 1..100 (по умолчанию 25) и `order`: `rank` (по умолчанию, с разделителем на границе видимой части) или `recent`. Сохранённые ссылки на участников заменяются на текущее имя (кроме `raw`) |
| `/nep memory channel [channel]` | С указанным каналом: полная сохранённая заметка (назначение, темы, тон, количество сообщений, активность, самые активные авторы). Без канала: таблица всех каналов, которые знает персонаж, по дате последнего сообщения |
| `/nep memory server` | Серверные заметки: как люди общаются, как начинаются разговоры, внутренние шутки, факты о себе, плюс количество профилей, каналов и записей лорбука |
| `/nep memory recent` | Показать текущие недавние заметки сервера: заметки внутри окна `memory.recentHours`, новейшие первыми, с id, моментом, каналом и весом |
| `/nep memory refresh <user>` | Принудительно обновить портрет участника. Выборка вписывается под 50k-рельс по токенам. Расходует `memory.portraitRefreshPerDay`. Когда у участника в очереди ожидает голосовой элемент character (`voice-pending`), ответ об этом сообщает и отказывает, если обновление не принудительное |
| `/nep memory forget <user>` | Удалить сохранённый профиль, приватную память и элементы голосовой очереди (включая уроки от этого участника). Ожидает завершения текущего батча анализатора |
| `/nep memory affinity <user> [score] [reason]` | Показать или установить отношение (-100..100) |
| `/nep memory wipe <confirm>` | Стереть всю память анализатора для этого сервера; для подтверждения введите точное имя сервера. Удаляется: профили участников и их приватная память, серверные привычки (паттерны, стартеры, внутренние шутки), выученные элементы, голосовая очередь, недавние заметки, рейтинг эмодзи, карта каналов, лор анализатора, прогресс прогрева. Остаётся: владельческий лор, кэш описаний медиа, библиотека GIF, калибровка токенов, дневные счётчики, расписание спонтанных ходов. Ожидает завершения текущего батча анализатора |
| `/nep private show <user>` | Показать приватную память участника: отношения, интересы, детали, эпизоды, приватное и эффективное отношение, сегодняшний счётчик ответов. Нет приватного слоя — простой ответ, не ошибка. Только для владельцев; нельзя выдать через разрешения |
| `/nep private forget <user>` | Удалить только приватную память участника; публичный профиль сохраняется. Ожидает завершения текущего батча анализатора. Только для владельцев; нельзя выдать через разрешения |
| `/nep private purge <user>` | Удалить сообщения бота в ЛС с участником (сканирует до `private.purgeMaxMessages`), затем его приватную память. Сообщения участника остаются. Отклоняется на паузе. Только для владельцев; нельзя выдать через разрешения |
| `/nep diary set <channel>` | Указать канал для дневника. Бот должен иметь права на просмотр, отправку, чтение истории и прикрепление файлов. Записывает `diary.channelId` в `config.local.json`. Если история дневника пуста, заполняет её из прошлых постов персонажа в этом канале. Отвечает каналом, количеством заполненных постов и сегодняшним планом |
| `/nep diary show` | Показать канал дневника, сегодняшние слоты с метками выполнения (в `bot.timezone`), использованные сегодня посты и картинки, голод каждого окна с серией тихих дней, размер истории |
| `/nep diary off` | Убрать `diary.channelId`. Файл истории дневника остаётся |
| `/nep diary post [kind] [topic]` | Принудительно опубликовать один пост прямо сейчас. Ждёт до `diary.forceWaitMs` завершения текущего хода; при истечении ожидания отвечает `busy`. Необязательный ключ вида (например `selfPicture`, `thought`) переопределяет выбор планировщика; неизвестный вид отклоняется со списком доступных. Необязательная тема в свободной форме направляет пост на указанный предмет. Подчиняется дневным лимитам; отказ по лимиту указывает ключ настройки и текущий/максимальный счёт. Вид с картинкой отклоняется, когда пост не может содержать картинку: ответ указывает лимит и его счётчики, когда причиной был лимит, или говорит `pictures` в остальных случаях. Вид-набор (`diary.setKinds`), у которого вышло меньше `diary.set.minPosted` картинок, ничего не публикует и отвечает `refused (set-short)`. В dry-run пост зеркалируется, а не отправляется |
| `/nep alias add <user> <name>` | Добавить псевдоним в чате; подтверждается сразу |
| `/nep alias remove <user> <name>` | Удалить псевдоним из чата |
| `/nep learned list` | Список уроков с id, кто научил, количество наблюдений |
| `/nep learned add <text>` | Добавить урок вручную (без учителя, подтверждено) |
| `/nep learned remove <id>` | Удалить урок |
| `/nep lore add <title> <keys> <text> [always]` | Добавить или перезаписать запись лорбука; запись с тем же заголовком заменяется и помечается как владельческая, и анализатор её больше не трогает |
| `/nep lore list [query]` | Список записей лорбука |
| `/nep lore show <id>` | Показать запись лорбука |
| `/nep lore remove <id>` | Удалить запись лорбука |
| `/nep emoji status` | Показать рейтинг эмодзи: размер, топ-10 имён с количеством, время последнего заполнения из истории |
| `/nep emoji rescan` | Очистить рейтинг использования и пересчитать из истории каналов |
| `/nep gifs status` | Показать библиотеку GIF: размер, топ-10 с хэндлом, количеством и подписью или именем, время последнего заполнения из истории, отправлено сегодня / `gifs.maxPerDay`, просмотрено сегодня / `media.gif.maxPerDay`, `captions:` (сколько записей библиотеки: просмотрено / однокадровое / неудачный просмотр / нет) и `caption format:` (просмотрено с полями / просмотрено в старом формате, требует переописания / без подписи) |
| `/nep gifs rescan` | Обнулить счётчики использования и пересчитать из истории каналов; записи и хэндлы сохраняются, ненайденные записи остаются с нулём, пока их не вытеснит лимит размера |
| `/nep gifs recache` | Удалить однокадровые подписи GIF вне библиотеки, поставить в очередь просмотренные записи в старом формате (без поля `reaction`) на переописание, затем просмотреть в фоне до `gifs.recachePerRun` GIF из библиотеки, начиная с самых старых. Дневной лимит `media.gif.maxPerDay` общий с живыми просмотрами; 300 записей по 50 за запуск требуют 6 команд за минимум два дня UTC. Ответ приходит сразу; следить за прогрессом через `/nep gifs status`. Отклоняется на паузе, во время прогрева или когда GIF не просматриваются |

Сообщение должно быть от персонажа; ссылка на другой сервер, личное сообщение, канал, недоступный боту, удалённая цель ответа и чужое сообщение отклоняются |

| `/nep mentor cases` | Список кейсов: id, состояние (`new`, `passing`, `failing`), цель, последний балл, число моментов (если есть), текст до 80 символов |

| `/nep mentor check` | Воспроизвести сохранённые ситуации каждого активного кейса, у которого есть прогон, с `mentor.check.samples` сэмплов на каждую (реальные моменты используют `mentor.anchor.samples`). | `/nep mentor status` | Модель, включён или нет, потрачено токенов / лимит, кейсы по состояниям, текущий прогон (показывает `, stopping` пока остановка ожидается), и последний завершённый прогон (`last:`): кейс, результат, медиана overall, оценённые ответы, токены и время завершения |
| `/nep access grant <command> [role] [user]` | Открыть команду, группу или `*` всем (по умолчанию), роли или пользователю. `private.*`, `mentor.*` и `access.*` исключены; см. выше |
| `/nep access revoke <command> [role] [user]` | Отозвать разрешение у всех (по умолчанию), роли или пользователя |
| `/nep access list` | Список всех текущих разрешений доступа |

## Команды участников

`/nep pings` — единственная команда, которую любой участник сервера может выполнить без разрешения `bot.access`. `features.memberCommands: false` ограничивает доступ владельцами.

| Команда | Описание |
|---|---|
| `/nep pings [mode]` | Показать или изменить, уведомляет ли вас персонаж своими сообщениями. Без `mode`: текущая настройка. `on` / `off`: установить предпочтение. Когда выключено, ответ на ваше сообщение не содержит пинга, а @упоминание вас в тексте персонажа отображается, но не уведомляет. Текст персонажа остаётся прежним. Эфемерный ответ: `Pings: on` или `Pings: off`. Хранится по серверу, переживает перезапуски, удаляется только по `/nep memory wipe` |
