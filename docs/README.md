# Documentation

Start with the task you want to do. These guides describe the engine and its public contracts. Personal settings, memories and credentials belong to your installation's `data/` folder.

| Guide | Use it to |
|---|---|
| [Getting started](getting-started.md) | Install a persona and connect Discord |
| [CLI](cli.md) | Talk to the persona, inspect its health and change settings |
| [Setup](setup.md) | Configure services and agent backends |
| [Keys](keys.md) | Select models and manage credentials |
| [Proxy](proxy.md) | Send outbound traffic through one proxy |
